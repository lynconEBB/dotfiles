# Dotfiles

Personal configuration files for my development environment.

## Available Configurations

### Neovim

The `nvim/` directory contains a Lua-based Neovim configuration managed with
`lazy.nvim`. It includes editor defaults, custom keymaps, LSP support,
completion, formatting, fuzzy finding, Git integration, Treesitter, file
navigation, and Unreal Engine development helpers.

### GlazeWM

The `.glzr/glazewm/` directory contains a Windows tiling window manager
configuration. It defines workspaces, gaps, window rules, visual effects, and
keyboard shortcuts for navigating and managing windows.

These files are tailored to my own workflow and may require local tools or
paths to be adjusted before use on another machine.
